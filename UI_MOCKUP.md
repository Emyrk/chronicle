## Status Indicators

```
Encounter Types:
  🎯 BOSS  - Named boss encounter (red badge)
  🗡️ TRASH - Trash mob groups (gray badge)

Encounter Results:
  ✅ Kill  - Boss defeated successfully
  ❌ Wipe  - Group wiped or reset

Unit Types:
  👤 Player - Actual player character
  🤖 NPC    - Non-player character or pet
```

## Interactive Elements

```
┌─────────────────────────────────────────────────┐
│ Hover Effects:                                  │
│ • Table rows: Highlight on hover               │
│ • Buttons: Color change + shadow               │
│ • Source items: Shift right + darken           │
│                                                 │
│ Click Actions:                                  │
│ • 📊 Details button → Open modal               │
│ • Modal overlay → Close modal                  │
│ • ✕ button → Close modal                       │
│                                                 │
│ Animations:                                     │
│ • Modal: Fade in (0.2s)                        │
│ • Progress bars: Smooth width transition       │
│ • Hover states: Transform + color (0.2s)       │
└─────────────────────────────────────────────────┘
```
