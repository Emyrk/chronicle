What things on the UI can affect variants?

- Player Selection (url)
- Enemy Selection (url)
- Encounter Selection (url)
- Layout
- Panels


## Layers

- View (icon/name)
 - Configured outside the instance page. Sets up things like layout 
- Variant
  - Things like "By Unit", "By Name"
- Ephemeral
 - Things like per second, that do not change the underlying data.
